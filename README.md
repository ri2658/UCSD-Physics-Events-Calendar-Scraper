# UCSD-Physics-Events-Calendar-Scraper
Scrapes UCSD Physics colloquia, seminars, and other departmental events from UCSD's Physics Events page, and updates a Google Calendar .ics file. 
Made this because:
1. there wasn't any known regularly updated calendar exports
2. wanted to preview web scraping skills learned in DSC 80
3. The Physics' Department virtual advising center was closed at the time.
